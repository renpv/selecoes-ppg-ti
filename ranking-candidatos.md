## Como concorrer no único edital aberto (PPGCC/IFCE 43/2026)

- Inscrição: até **2026-11-21**, sem taxa, [IODA](https://inscricao.ppgcc.ioda.com.br/) — **um** código de tema.
- Prova escrita: **2026-12-04 (sexta)**, presencial, nota mínima 3,0 (retificação nº 01; não é mais 05/12).
- Depois: arguição 14–18/12 e currículo (nota = pontos do Anexo VI ÷ 10, retificação nº 02).
- Média simples das três etapas. Dedicação **≥ 20 h diurnas**. Diploma STEM.
- Conteúdo da prova: Anexo VII (lógica, programação, POO). Ler o PDF antes de se inscrever.

Entre #4 e #8, escolha **um**: CA01 ou CA02 se o interesse for arquitetura/metodologia de software; CA04/CA05 se for sistemas/infra; RCSD02 se for ferramentas (e há 2 vagas).

## Como se preparar para #1 e #2 (plano A acadêmico)

Enquanto o IFCE é tático, o trabalho de fundo é um **pré-projeto de ES** (métodos, técnicas, ferramentas ou arquitetura) + Lattes 2023–2026 + duas cartas.

- **UECE:** inscrição histórica por e-mail; projeto + pontuação + cartas + entrevista. Checar [uece.br/ppgcc](https://www.uece.br/ppgcc/) toda semana (o aviso de set/out/2026 já passou sem edital).
- **MDCC:** SIGAA + formulário; doutorado exige projeto temático no edital. Checar [mdcc.ufc.br/pt/processo-seletivo](https://mdcc.ufc.br/pt/processo-seletivo/).
